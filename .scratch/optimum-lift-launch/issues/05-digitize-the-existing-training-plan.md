# Digitize the existing Training Plan as Product #1

Type: task
Status: open

## Question

Turn the existing physical Training Plan into a sellable Download.

The source is roughly ten spreadsheets, one per week, each holding four days of training. Spreadsheets are not a familiar tool here, and the plans have been described as "not really solid" — so this is not pure transcription. Decide the Plan's structure and format once, deliberately, because the first three Plans will set the template every later Plan follows.

## Definition of done

One finished PDF Download, ready to sell. The answer records the Plan's structure (how a week, a day, an exercise, and a set are laid out) so Product #2 does not reinvent it.

## Notes

Unblocked — this runs in parallel with the entire payment thread, and it should, because a shop with no catalogue cannot launch no matter how good the checkout is.

**Do not** build tooling to generate this. Author it by hand. Tooling is fog on the map, deliberately: building it before three Plans exist means building it around a format that is about to change.

Quality caveat worth taking seriously: faster production of mediocre Plans is a worse outcome than slower production of good ones. If the content is weak, that caps the business before the shop does.
