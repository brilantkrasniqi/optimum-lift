# Plan files

One Plan file per Product's Training Plan: the Plan as JSON, naming Exercises by library key. Claude writes them here, or they are exported from wp-admin (**Export as JSON**) or with `wp ol-plans export-plan`. The file name is the Plan's slug.

Inside the `wpcli` container this folder is `/plans`. How to write, check and import one: `docs/plan-files.md`.
